# Dil Creative Studio - Website

A modern, professional website for Dil Creative Studio showcasing design and branding services.

## 📋 Features

### Pages
- **Home** - Eye-catching landing page with hero section and key features
- **About** - Studio story, values, and mission
- **Services** - Detailed service offerings with pricing tiers
- **Portfolio** - Showcase of past projects with filtering capabilities
- **Contact** - Contact form with FAQ section and multiple contact methods

### Key Features
✨ Responsive design (mobile, tablet, desktop)
🎨 Modern, professional aesthetic with gold accents
📱 Mobile-friendly navigation with hamburger menu
🎯 Portfolio filtering by service category
📧 Contact form integrated with WhatsApp
💬 Interactive elements and smooth animations
🚀 Fast loading and optimized performance

## 🛠️ Technical Stack

- **HTML5** - Semantic markup

- **Responsive Design** - Mobile-first approach

## 🔧 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #FFD700;
    --dark-color: #111827;
    --light-color: #f5f5f5;
    --text-color: #222;
}
```

### Contact Information
Update contact details in footer sections across all HTML files.

### Social Media Links
Update social media URLs in the contact page social buttons section.
